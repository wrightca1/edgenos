## Retracted — and this is the more useful column

| claim | why it fell |
|---|---|
| "One spliced replay word kills Et2, and it reverses" | the unspliced replay produces a dark Et2 too. The 4-run alternation was a ~5% coincidence |
| "Et2 was damaged by a write test" | Et2 was never damaged; it is a 50% coin |
| "`0x0815 → 0x0c15` is a lock beginning to fail" | bit 10 toggles on the *working* port in the same log |
| "`{0x20, 0xe0}` = `{DECREMENT, CHECKSUM}`" | they do not co-occur, and disabling `0xe0` in two slices changed nothing |
| "Punted frames carry no F64 tag" | `PORTD_DEBUG=1` dumps **one** frame and mine was a runt. 4 of 7 are tagged |
| "Frames span descriptors; bit 3 is EOP" | RX buffers are 2048 bytes, and good frames have bit 3 **clear** — the opposite of EOP |
| "Slices 4-8 stop the frame" | the box wedged at slice 3 and never recovered; five readings of one dead state |
| "Banks 7/9 drive the TTL" (predicted in advance) | both unchanged; the TTL is not operand-driven at all |
| "Command byte `0x05` decrements the TTL" | it is `SKIP 6`. Disabling it *moved* the decrement 6 bytes earlier, onto the IP length high byte — proved by three payload sizes |
| "It cannot be `SKIP 6`, nothing shifted" | a SKIP before a **single-byte transform** displaces nothing; it relocates one edit. Only INSERT/DELETE shift a frame. I tested for the wrong signature |

## The method lessons, which transfer

- **A single boot measures nothing.** Et2 links half the time, so the null hypothesis is a coin, not
  "no effect". Claims need n per arm and a reported count.
- **Design experiments to be falsified.** At a 50% base rate, a hypothesis predicting a *zero* costs
  5 boots; one predicting a *shift* costs ~32 per arm. That asymmetry is why the SPICO question got
  answered and the Et2 mechanism did not.
- **Absence of a failure signal is not success.** Zero `punt tag` lines, no `RESUME_FROM` marker, an
  empty diff — each was read as a result and each was an instrument that had not run.
- **Scale the check with the write.** Both incidents that cost hardware time — the RX reassembly and
  the corrupted MOD bank — were a write scaled up without its verification. `[ -n "$saved" ]` passes
  on a short capture and then the restore writes zeros over a live table.
- **Search without a shortlist when you can.** Three hand-picked leave-one-out tests found nothing
  because predicting which CAM entry fires needs a 48-bit key. Disabling whole slices needs no
  prediction, and it produced the answer in 20 tests — an answer that contradicted the shortlist.
- **Read the control column.** Every retraction above was caught by a control that was already in the
  same capture: Et1 in the settle trace, a working lane in the SerDes diff, an unperturbed probe.

## Where it stands

- Transit rig is working and documented in `tools/README-7150-harnesses.md`.
- A4 has its first *anchor* — opcode 0 = SKIP, measured three ways — not yet a command whose
  function is named. The generator problem splits into transform vs content commands.
- **`DECREMENT` is still unidentified** — it is a step *after* the skip, findable as the entry whose removal stops the TTL changing **without** relocating the edit.
- **Open:** bank 4's unchanged result against its MAC association; Et2's replay race (alpha13 now
  samples Et2 every 16k ops *inside* the replay, so a good and a dark trace will bisect it); B1.
  - ✅ **The bisection ran on 2026-08-17 and returned a negative: there is no replay race.** The
    replay's last write to any EPL is op 157,123, after which 29% of it executes without touching a
    port. See `SESSION-20260817.md`.
- ⚠ `mod_decode.py` reads `0x05`/`0x85` as the MAC rewrite on the same operand-5 reasoning that was
  just refuted for `0x05`. Slices 3/4 stopping the frame needs re-attributing.
